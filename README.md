A dependency-free JavaScript reader for CSV files with malformed quotes, ragged rows and mixed line endings. Import `run({text, header})` from `solve.js` to obtain the columns, rows and ordered error records.

The Node.js 22 competition entry point is `node main.ts`. It reads `cases.json` from `MAKEFUN_INPUT_DIR` (default `/input`) and writes `answers.json` into the existing `MAKEFUN_OUTPUT_DIR` (default `/output`).
